# Phase 10 — Admin, Moderation and Analytics

## Goal
Provide permission-managed operations without unsafe administrative shortcuts.

## Admin dashboard
Manage authorized users, listings, reports, assessments, verification, support cases and financial investigations. Use search, filters, pagination and sensitive-data masking.

## Moderation and actions
Record actor, action, reason, time and target for user/listing actions; support appeals where appropriate. Provide queues for reports, support, KYC review and financial investigation.

Do not provide unrestricted balance edits or a button that marks an external payment successful. Corrections must use approved, audited workflows.

## Audit and analytics
Audit sensitive admin actions. Provide privacy-conscious aggregate metrics for registrations, profile completion, learning, assessments, jobs, applications, confirmed hires, services, payment outcomes and support.

## Security and tests
Use strong admin authentication where supported, confirmations for destructive actions, bounded bulk actions and restricted exports. Test authorization, auditing, moderation access and sensitive-data restrictions.
